# Apex Gantt chart web component

Proof of concept web component wrapper for the Apex gantt chart type.

## Getting dev ready:

1. Clone the repository.
2. Install the dependencies.
3. Run `npm start` to look at some samples.
4. Run `npm test` to execute the test suite.
